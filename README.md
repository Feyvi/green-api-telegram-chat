# Telegram Chat

## Описание

React-приложение для отправки и получения текстовых сообщений в Telegram через GREEN-API.

Реализовано:

- подключение к GREEN-API по `idInstance` и `apiTokenInstance`;
- создание чата по номеру телефона;
- отправка текстовых сообщений;
- получение входящих текстовых сообщений;
- отображение сообщений в интерфейсе чата.

## Запуск

```bash
npm install
npm run dev
